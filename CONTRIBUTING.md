# Contributing to Shajara · شجرة الأنبياء

Thanks for helping build this. It is an early-stage scaffold, so the biggest help is turning the roadmap in the README into working code.

## Workflow
1. Branch from `main`: `feat/<short-name>` or `fix/<short-name>`.
2. Commit with [Conventional Commits](https://www.conventionalcommits.org/): `type(scope): description`.
3. Open a PR; fill the template; link an issue.

## Rules
- Keep the README's architecture/roadmap sections honest and up to date.
- Reuse the "open bases to fork" in the README before writing new code.
- Write tests for anything correctness-critical.
- Never commit secrets. Use `.env` (git-ignored) and add keys to `.env.example`.
